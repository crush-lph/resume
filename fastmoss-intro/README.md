# FastMoss 项目简历知识包

本目录用于给简历优化 Agent 提供可学习素材，建议优先读取以下文件：

1. `fastmoss_project_resume_knowledge.md`
2. `fastmoss_resume_seed.json`

推荐使用方式：

1. 先让 Agent 学习 `fastmoss_project_resume_knowledge.md`（理解项目技术深度与难点）。
2. 再让 Agent 基于 `fastmoss_resume_seed.json` 生成目标岗位定制版中英文简历 bullets。
3. 如果你有真实业务指标（DAU、转化率、性能耗时、上线周期），替换 JSON 里的占位指标后再二次生成。
