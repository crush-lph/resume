# Oumomo 项目简历知识包

本目录用于给简历优化 Agent 提供 Oumomo 项目素材，建议优先读取以下文件：

1. `oumomo_project_resume_knowledge.md`
2. `oumomo_project_experience_versions.md`

推荐使用方式：

1. 先让 Agent 学习 `oumomo_project_resume_knowledge.md`，理解项目背景、技术亮点、难点与证据索引。
2. 再基于 `oumomo_project_experience_versions.md` 选择适合目标 JD 的项目经历版本。
3. 如果有真实业务指标，如上传成功率、支付成功率、任务完成率、页面性能指标等，替换文档中的 `[X%]`、`[Xh]`、`[N]` 占位符后再投递。
