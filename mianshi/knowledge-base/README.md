## 复习原则

- 不只背结论，要能说清楚“为什么”。
- 每个知识点最好绑定一个项目例子。
- 每个优化题都要讲清楚“问题、定位、方案、结果”。
- 遇到 AI 前端题，不要只讲概念，要讲清前端边界、后端边界和安全边界。
