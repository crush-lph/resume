# 知识地图

## 主线一：React 前端

必须掌握：

- Hooks：`useState`、`useEffect`、`useRef`、`useMemo`、`useCallback`
- 渲染机制：虚拟 DOM、diff、`key`、Fiber、批量更新
- 组件设计：受控/非受控、状态提升、Context、自定义 Hook
- 性能优化：重复渲染、大列表、虚拟列表、懒加载、代码分割
- 工程化：React Router、Redux/Context/Zustand、Vite、Webpack
- 项目深挖：组件拆分、状态设计、接口管理、权限、性能、线上问题

## 主线二：AI 前端

必须掌握：

- SSE 与 WebSocket 的区别
- Token 与上下文窗口
- 流式文本渲染优化
- Prompt 管理
- RAG 前端展示
- Web Worker 在 AI 前端中的使用
- Markdown、公式和代码高亮渲染
- AI 接口慢时的体验优化

## 主线三：架构与安全

必须掌握：

- 企业级 AI Chat 桌面端架构
- 从 0 到 1 设计项目架构
- 支付系统策略模式抽象
- Prompt Injection 防护
- Electron 与 Tauri 选型
- 本地存储与安全
- 模型 Provider 抽象
- AI Agent 对前端开发模式的影响
- Vibe Coding 在团队内落地
