# 面试回答模板

## 原理题模板

适合问题：

- Fiber 是什么？
- 事件循环是什么？
- Vite 为什么快？

回答结构：

1. 先给定义
2. 再讲解决的问题
3. 再讲核心机制
4. 最后讲项目中的使用或影响

示例骨架：

```txt
它主要解决的是 X 问题。
核心机制是 Y。
在实际项目中，我会关注 Z。
如果继续追问，我会补充它的边界和常见坑。
```

## 性能优化题模板

适合问题：

- 流式文本渲染如何优化？
- 大列表如何优化？
- 页面卡顿如何定位？

回答结构：

1. 问题现象
2. 定位方法
3. 优化方案
4. 数据结果

示例骨架：

```txt
当时的问题是 X。
我先通过 Y 工具定位到瓶颈在 Z。
最终采用了 A、B、C 三个方案。
优化后结果是 D。
```

## 项目深挖题模板

适合问题：

- 你做过最难的项目是什么？
- 遇到过什么技术挑战？
- 如果重做一次会怎么优化？

回答结构：

1. 项目背景
2. 你的职责
3. 技术难点
4. 方案取舍
5. 结果数据
6. 复盘改进

示例骨架：

```txt
这个项目的背景是 X，我主要负责 Y。
最难的问题是 Z，因为它同时涉及 A 和 B。
我当时对比了几种方案，最后选择 C。
结果是 D，如果现在重做，我会进一步优化 E。
```

## 安全题模板

适合问题：

- 如何防 Prompt Injection？
- AI 返回内容如何防 XSS？
- 桌面端本地密钥如何处理？

回答结构：

1. 先说明风险是什么
2. 再说明前端能做什么
3. 再说明后端必须做什么
4. 最后说明监控和兜底

示例骨架：

```txt
这个风险不能只靠前端解决。
前端可以做 X，但核心边界应该在后端的 Y。
另外还需要 Z 作为审计和兜底。
```
