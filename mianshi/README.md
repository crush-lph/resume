# 面试复习目录

这套材料基于当前 `README.md` 简历生成，重点围绕简历中最容易被追问的项目与能力点展开。

## 文件说明

- `面试问题题库.md`：按模块整理高频追问问题，适合每天抽题自测。
- `14天复习计划.md`：按两周节奏安排复习重点、输出物与模拟面试任务。
- `项目复盘口径模板.md`：用于准备每个核心项目的 2 分钟介绍、技术细节、指标口径与风险问题。

## 复习建议

- 优先准备 FastMoss 数据平台、FastMoss 小程序、ClawDream 三个项目，这三段最能体现你的架构、性能、AI 提效和业务落地能力。
- 每个项目都按“背景 -> 目标 -> 方案 -> 难点 -> 结果 -> 复盘”准备，不要只背技术点。
- 所有指标都准备好口径，例如 SEO 收录、FCP/LCP、构建时间、包体积、新渠道接入周期等，避免面试官追问时说不清楚。
- AI 辅助研发不要只讲工具名，要讲它进入了哪些研发环节、如何约束质量、如何评审合入。
