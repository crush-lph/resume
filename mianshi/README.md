## 以后检索资料的默认路径

以后我在这个 `mianshi/` 目录里工作时，会按这个顺序找资料：

1. 先看这份 [README.md](/Users/lipenghu/Desktop/hulia/resume/mianshi/README.md) 的主题映射。
2. 再跳到对应的面经、知识库或代码示例。
3. 如果当前资料没有，再补充到正确的细分文档，而不是把所有内容继续堆在一个文件里。

这样可以保证：

- 入口始终统一。
- 同类问题能快速定位。
- 新资料沉淀后不会丢失在目录里。
