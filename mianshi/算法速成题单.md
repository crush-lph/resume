# 算法速成题单

## 使用方式

- 目标不是刷很多题，而是尽快建立题型识别能力。
- 每天控制在 `3~6` 题，做完必须复盘。
- 每道题至少写下这 4 句：
  - 这题属于什么模型
  - 暴力解法是什么
  - 优化点是什么
  - 我第一次为什么没想到

## 刷题规则

### 先刷主干，再补难点

- 第一优先级：数组、链表、哈希表、字符串
- 第二优先级：二分、双指针、滑动窗口、栈队列、二叉树
- 第三优先级：回溯、贪心、动态规划、单调栈

### 一道题至少过三遍

- 第 1 遍：独立做
- 第 2 遍：看题解后自己重写
- 第 3 遍：隔天脱稿再写一次

### 每天固定输出

- `1` 份错题复盘
- `1` 份模型总结
- `1` 次口头讲题

## 7 天速成题单

### 第 1 天：数组 + 二分查找

目标：建立数组感知和二分区间意识。

- `704. Binary Search`
- `35. Search Insert Position`
- `69. Sqrt(x)`
- `367. Valid Perfect Square`
- `27. Remove Element`

复盘重点：

- 左闭右闭和左闭右开的区别是什么
- `while (left <= right)` 和 `while (left < right)` 分别对应什么区间定义

### 第 2 天：双指针 + 滑动窗口

目标：把 `O(n^2)` 的直觉题改写成 `O(n)`。

- `977. Squares of a Sorted Array`
- `209. Minimum Size Subarray Sum`
- `283. Move Zeroes`
- `344. Reverse String`
- `151. Reverse Words in a String`

复盘重点：

- 快慢指针和相向双指针分别适合什么题
- 滑动窗口为什么不是 `O(n^2)`

### 第 3 天：链表

目标：不再害怕指针移动。

- `203. Remove Linked List Elements`
- `206. Reverse Linked List`
- `24. Swap Nodes in Pairs`
- `141. Linked List Cycle`
- `142. Linked List Cycle II`

复盘重点：

- 虚拟头节点解决了什么问题
- 每次改指针时，哪些节点必须先保存

### 第 4 天：哈希表 + 字符串

目标：会识别查重、计数、配对问题。

- `242. Valid Anagram`
- `1. Two Sum`
- `349. Intersection of Two Arrays`
- `202. Happy Number`
- `383. Ransom Note`

选做：

- `28. Find the Index of the First Occurrence in a String`

复盘重点：

- 什么时候该用数组计数，什么时候该用 `map` / `set`
- 为什么哈希表是“空间换时间”

### 第 5 天：栈队列 + 二叉树基础

目标：建立递归和容器题的基本骨架。

- `20. Valid Parentheses`
- `232. Implement Queue using Stacks`
- `225. Implement Stack using Queues`
- `144. Binary Tree Preorder Traversal`
- `102. Binary Tree Level Order Traversal`

复盘重点：

- 栈和递归的关系是什么
- 层序遍历为什么天然适合用队列

### 第 6 天：二叉树进阶 + 回溯入门

目标：把“遍历树”和“搜索树”区分开。

- `226. Invert Binary Tree`
- `101. Symmetric Tree`
- `104. Maximum Depth of Binary Tree`
- `77. Combinations`
- `78. Subsets`

复盘重点：

- 二叉树递归函数的参数和返回值如何设计
- 回溯题里的“路径、选择列表、终止条件”分别是什么

### 第 7 天：贪心 + 动态规划入门

目标：开始区分局部最优和状态转移。

- `455. Assign Cookies`
- `122. Best Time to Buy and Sell Stock II`
- `509. Fibonacci Number`
- `70. Climbing Stairs`
- `198. House Robber`

复盘重点：

- 贪心为什么能贪
- 动态规划里 `dp[i]` 表示什么
