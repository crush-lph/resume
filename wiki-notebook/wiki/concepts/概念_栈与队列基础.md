    # 概念_栈与队列基础

    ## 定义与要点
    - 栈是先进后出，队列是先进先出。
- 用一个结构模拟另一个结构，是理解抽象行为而非 API 的经典方式。
- 很多图形化处理和遍历顺序题都依赖这两类容器。

    ## 本知识库中的应用
    - 对应专题来源页会沉淀该方法的典型题型、边界和适用条件。
    - 回答问题时，可以把它视为该算法专题的抽象层，而不是单题笔记。
